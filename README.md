# Machine Learning Capstone

This repository contains the Machine Learning Capstone project, structured into three comprehensive tracks: **Regression** (Solar Power Generation), **Classification** (Steel Industry Energy Consumption), and **Clustering** (Solar Power Plant Operational Regimes).

## 📝 Problem Statements

- **Regression Track (Solar Power)**: Predict the total AC power generated by a solar power plant based on meteorological conditions and module sensor data (irradiance, ambient temperature, module temperature). The goal is to optimize grid integration and power distribution planning.
- **Classification Track (Steel Industry)**: Predict the categorical energy load type (`Light_Load`, `Medium_Load`, `Maximum_Load`) of a steel industry facility based on detailed power consumption metrics. This aids in dynamic pricing, load balancing, and energy efficiency.
- **Clustering Track (Solar Regimes)**: Uncover latent operational regimes and generation states of the solar plant in an unsupervised manner using multi-sensor environmental telemetry (irradiance, ambient/module temperatures, wind speed, currents) without label guidance. Discovered clusters are validated post-hoc against physical power generation to guide condition monitoring and plant dispatch.

## 📊 Dataset Descriptions

- `solar_generation.csv`: Contains high-frequency continuous telemetry readings from a solar power plant. Features include DC/AC power output, module and ambient temperatures, wind speed, and solar irradiance.
- `Steel_industry_data.csv`: Contains high-frequency continuous readings from a smart meter at a steel industry facility. Features include active and reactive power consumption (kWh and kVarh), leading/lagging power factors, CO2 emissions, and temporal variables.

## ⚙️ Environment Setup & How to Run

To run this project locally and view the results, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd Machine_Learning_Capstone
   ```

2. **Set up a Virtual Environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On macOS/Linux
   # venv\Scripts\activate   # On Windows
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
   *Open `regression.ipynb`, `classification.ipynb`, or `clustering.ipynb`, click **Kernel**, and select **Restart & Run All** to execute the pipelines end-to-end without errors.*

## ⚖️ Rubric Compliance

All notebooks strictly adhere to the capstone guidelines:
- **Reproducibility:** `random_state=42` is used universally across all stochastic routines.
- **Data Leakage Prevention:** All scalers (`StandardScaler`) and encoders are fitted **strictly on the training split** and transformed across evaluation splits.
- **Unsupervised Label Isolation (*Clustering*):** Target `AC Power in Watts` is segregated during training and utilized exclusively for post-hoc physical validation and regime profiling.
- **Visualizations:** All plots utilize `tight_layout()`, labeled axes, clear titles, and colorblind-friendly palettes (`Set2`). All required visualisations (Elbow curve, Dendrogram, PCA 2D projections, and t-SNE non-linear embeddings) are included.
- **Narrative & Justification:** Every major code block is accompanied by a Markdown cell explaining the underlying intuition, insights, and model selection justifications.
