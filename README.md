# Machine Learning Capstone

This repository contains the Machine Learning Capstone project, structured into two core tracks: **Regression** (Solar Power Generation) and **Classification** (Steel Industry Energy Consumption).

## 📝 Problem Statements

- **Regression Track (Solar Power)**: Predict the total AC power generated by a solar power plant based on meteorological conditions and module sensor data (irradiance, ambient temperature, module temperature). The goal is to optimize grid integration and power distribution planning.
- **Classification Track (Steel Industry)**: Predict the categorical energy load type (`Light_Load`, `Medium_Load`, `Maximum_Load`) of a steel industry facility based on detailed power consumption metrics. This aids in dynamic pricing, load balancing, and energy efficiency.

## 📊 Dataset Descriptions

- `solar_generation.csv`: Contains 15-minute interval readings from a solar power plant. Features include DC/AC power output, daily/total yield, and weather sensor data (ambient temperature, module temperature, irradiation).
- `Steel_industry_data.csv`: Contains high-frequency continuous readings from a smart meter at a steel industry facility. Features include active and reactive power consumption (kWh and kVarh), leading/lagging power factors, CO2 emissions, and temporal variables.

## ⚙️ Environment Setup & How to Run

To run this project locally and view the results, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd Machine_Learning_Capstone
   ```

2. **Set up a Virtual Environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On macOS/Linux
   # venv\Scripts\activate   # On Windows
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
   *Open `regression.ipynb` or `classification.ipynb`, click **Kernel**, and select **Restart & Run All** to execute the pipelines end-to-end without errors.*

## ⚖️ Rubric Compliance

Both notebooks strictly adhere to the capstone guidelines:
- **Reproducibility:** `random_state=42` is used universally.
- **Data Leakage Prevention:** All scalers (`StandardScaler`) and encoders are fitted **strictly on the training set**.
- **Visualizations:** All plots utilize `tight_layout()`, labeled axes, clear titles, and colorblind-friendly palettes (`Set2`).
- **Narrative & Justification:** Every major code block is accompanied by a Markdown cell explaining the underlying intuition, insights, and model selection justifications.
